# Data

This repository redistributes **code, methodology, and aggregate results**.
It does **not** redistribute cohort expression matrices, clinical tables,
full-transcriptome source downloads, or recovered participant identifiers.

## What is in Git

| Path | Role | Classification |
|---|---|---|
| `data/processed/metabric/*.json`, gene-mapping report, clinical *field* counts | Preparation metadata (no sample-level expression) | Safe metadata |
| `data/processed/discovery/` inventories, fingerprints, README | Discovery provenance metadata | Safe metadata |
| `data/processed/cptac_linkedomics/` inventory / fingerprint / provenance report | LinkedOmics CPTAC-BRCA *reference* metadata | Safe metadata only |

## What is intentionally excluded from Git

| Path / pattern | Why |
|---|---|
| `data/processed/metabric/metabric_pam50_4class.csv` | Analysis-ready 50-gene expression + sample IDs — prepare locally |
| `data/processed/metabric/excluded_samples.csv` | Sample-level exclusion log |
| `data/raw/metabric/` | Full Illumina HT-12 v3 microarray (~657 MB) + patient/sample clinical tables |
| `data/raw/cptac_linkedomics/` | LinkedOmics RNAseq `.cct` and clinical `.tsi` (includes age, race) |
| `data/external/` | Duplicate LinkedOmics downloads |
| `legacy/cptac.csv`, `legacy/cptac_subtype.csv` | Full-transcriptome laboratory export + clinical demographics |
| Discovery PAM50 CSVs (integer-index or recovered-ID) | CPTAC-derived expression; recovered IDs are not redistributed |
| Sample-map CSVs under `artifacts/discovery_*` | Re-identification maps |

These files may exist **locally** after you download/prepare data. They must not be committed.

The MIT license in `LICENSE` applies to **code and documentation only**. It does
not relicense METABRIC, CPTAC, or LinkedOmics data.

## METABRIC (principal cohort)

- **Study:** Breast Cancer (METABRIC, Nature 2012 & Nat Commun 2016), cBioPortal `brca_metabric`.
- **Citations:** Curtis et al. Nature 2012; Pereira et al. Nat Commun 2016; Rueda et al. Nature 2019.
- **Portal:** https://www.cbioportal.org/study/summary?id=brca_metabric
- **cBioPortal Datahub license:** [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1.0/)
- **Profile used:** mRNA expression (Illumina HT-12 v3 microarray), log2 intensity (`datatype=CONTINUOUS`). This is **not** a raw CEL dump.
- **Analysis matrix:** 50 PAM50 genes × 1608 samples with labels in {LumA, LumB, Her2, Basal}. Claudin-low, Normal, and NC labels are excluded (see `excluded_samples.csv` locally / gene-mapping report in Git).

### Obtain and prepare

1. Download the cBioPortal METABRIC study archive.
2. Place at least these files under `data/raw/metabric/`:
   - `data_mrna_illumina_microarray.txt`
   - `data_clinical_patient.txt`
   - `data_clinical_sample.txt`
   - corresponding `meta_*.txt` files
3. From the repository root:

```powershell
python scripts\prepare_metabric.py
python scripts\test_prepare_metabric.py
```

The preparation script is the source of truth for probe mapping (Entrez ID, highest-variance probe) and 4-class filtering.

## Discovery (auxiliary / historical)

Internal cohort key: **`discovery`**. Do not relabel scientific outputs as CPTAC in paper text solely because class counts match.

The original laboratory source CSV is **not** in this public snapshot. A later
audit recovered putative CPTAC Patient_IDs by expression matching; that
recovered-ID matrix is also excluded. Provenance notes:
`data/processed/discovery/discovery_provenance_report.md`.

```powershell
python scripts\prepare_discovery.py
python scripts\test_prepare_discovery.py
```

`load_cohort("discovery")` requires the local processed matrix
`data/processed/discovery/discovery_pam50_4class.csv` (generated by prepare, not in Git).

## CPTAC LinkedOmics (reference only)

Public download: https://www.linkedomics.org/data_download/CPTAC-BRCA/

This cohort is **not** the OriginalRFECA TARGET-WISE freeze. Preparation script: `scripts/prepare_cptac_linkedomics.py`. Source `.cct` / `.tsi` files are gitignored.

## Schema of analysis-ready matrices

```
sample_id, <50 PAM50 genes in canonical order>, PAM50
```

Canonical gene order is `PAM50_GENES` in `src/bcimpute/config.py`. Labels are `LumA`, `LumB`, `Her2`, `Basal`.
